- HTTP access log bỏ query string vì query có thể chứa OAuth code hoặc reset token. Không đổi giao diện hiện tại.

## Chạy lại an toàn

Trong PowerShell, đặt `TEST_DATABASE_URL` trỏ database thử riêng, schema `vitest_codex_review`, rồi chạy `npm test`. Global setup xóa và tạo lại **schema thử đó**. Không trỏ tới database người dùng thật. Để chạy API/E2E, dùng schema local khác đã migrate, đặt `DATABASE_URL`, `JWT_ACCESS_SECRET`, `JWT_REFRESH_SECRET`, `PORT`, `APP_URL` và `E2E_BASE_URL` tương ứng. Không sao chép `.env` production vào môi trường này.

`render.yaml` vẫn mang tên tài nguyên blueprint cũ `so-moc-finance`. Lịch sử dự án cho biết dịch vụ đang dùng là `walletmaycry-finance`, còn dịch vụ cũ đã suspend. Trước khi áp dụng blueprint, phải đối chiếu mapping tài nguyên thật để tránh tạo thêm dịch vụ/database. Bản nhánh này chỉ cập nhật đường dẫn probe; không thay cấu hình tài nguyên đang chạy.
